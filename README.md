# Java Daily Practice

A structured, hands-on journey to learning **Core Java, problem-solving,
and the foundations of Java development**---one day at a time.

This repository documents my daily learning through code examples,
practice problems, and small exercises. The goal is to build strong
fundamentals, write clean and readable Java, and maintain a consistent
record of progress.

## Goals

-   Build a strong foundation in Java syntax and programming
    fundamentals.
-   Practice concepts by writing and running code---not just reading
    theory.
-   Improve logical thinking and problem-solving skills.
-   Learn object-oriented programming and essential Java APIs.
-   Practice data structures and algorithms in Java.
-   Track learning consistently through meaningful Git commits.

## Daily Practice Workflow

1.  Study one concept.
2.  Write a small example to understand it.
3.  Solve a few related practice questions.
4.  Run the code and check the output.
5.  Commit the work with a clear message and push it to GitHub.
6.  Review previous concepts regularly.

### Example Git workflow

``` bash
git add .
git commit -m "Day 01: Java basics practice"
git push
```

Use a commit message that accurately describes the work completed that
day.

## Coding Principles

-   Prefer clear, descriptive class, method, and variable names.
-   Keep examples focused on the concept being practiced.
-   Add comments when they explain *why* something is done.
-   Test code before committing it.
-   Revisit mistakes and improve earlier solutions when useful.
